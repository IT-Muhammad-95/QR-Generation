# Инструкция по установке генератора QR-кода:

Это пошаговая инструкция по установке генератора QR-кода

### Шаг 1

Для начала откроем терминал. Для этого зажмите клавиши `Win` + `R`, в появившемся поле введите `cmd`, нажмите "ОК". Поздравляю, Вы открыли терминал.

Сразу же скачаем **Python** - язык, на котором работает наша программа. Для этого сначала проверим, скачан он или нет.

Для этого вставтье в терминал эту команду: 

```bash
python --version
```

Если вывело `Python 3.12.10` или другую версию - значит язык установлен. Если же нет - установим его этой командой:

```bash
winget install Python.Python.3.12
```

Готово, Python установлен! Можем переходить к следующим шагам.

---

### Шаг 2

Теперь нужно перейти непосредственно в саму папку программы. Для этого нужно ввести 2 команды:

```bash
dir /s /b /ad "repository 3"
```

Чуть погодя, программа выдаст полный путь. Вам нужно его скопировать и вставить на место слова "`ПУТЬ`".

```bash
cd "ПУТЬ"
```

Теперь Вы находитесь непосредственно в папке программы. Создадим виртуальное окружение для программы. Вставьте эту команду:

```bash
python -m venv .venv
```

Теперь активируем его следующей командой:

```bash
.venv/Scripts/activate
```

Затем установим зависимости, без которых программа не будет работать. Для этого вставьте команду:

```bash
pip install requirements.txt
```

Отлично, все готово к запуску! Перейдите в шаг 3

---

### Шаг 3

Наконец, можно запустить нашу программу. Для этого вставьте команду:

```bash
python main.py
```

**Готово!** Ваша программа успешно запустилась. **Приятного использования**!
